# dap-seq-rhodanobacter-2026
This repository contains code and data for the analyses of Rhodanobacter transcriptional regulators and TF-binding motifs.

## Requirements

* Python 3 with openpyxl library

* Biopython [https://biopython.org/]

* dRep [https://github.com/MrOlm/drep]

* MUMmer [http://mummer.sourceforge.net/] (dRep dependency)

* fdrMotif [https://www.niehs.nih.gov/research/resources/software/biostatistics/fdrMotif]


## Assign genes to DAP-seq peaks

The make_peaks_table_xlsx.py file assigns a gene to a peak if the peak summit is within the upstream region of the gene or no farther than than 50 bp from the upstream region. 

The output file name is DAP-seq_peaks_dataset.xlsx. Running this script will overwrite the existing file with the same name.

```
cd peak_annotation 

python make_peaks_table_xlsx.py
```


## Dereplicate the set of Rhodanobacter genomes

**Pre-calculated list of dereplicated genomes is in the dereplicate_genome_set/Wdb.csv file. You can use this file and skip the deduplication step.**

The comparative analysis uses only non-coding upstream regions of genes, so the genome set was dereplicated with FASTA files of the upstream sequences as an input.
Since upstream sequences are relatively short, the dreplication step uses dRep with ANIn algorithm (nucmer alignment) and ignores genome completeness.

1. Export upstream regions of all genes

```
cd dereplicate_genome_set

python export_upstreams_drep.py
```

2. Run dRep 

```
sh run_drep.sh
```

The list of genomes for the dreplicated dataset will be generated in the /dereplicate_genome_set/drep_upstreams_nucmer/data_tables/Wdb.csv file.

## Calculate orthologs for comparative analyses

**You can skip this step and use pre-calculated orthologs from the orthologs/FW104-10B01_Orthologues.tsv and orthologs/FW510-R12_Orthologues.tsv files.**

1. Install (Orthofinder v2.5.5)[https://github.com/davidemms/orthofinder].

2. Export protein sequences

```
cd orthologs
python export_proteins.py

```

3. Run Orthofinder

```
sh run_orthofinder.sh
```

Ortholog files will be generated in the orthologs/out/Results_\*/Orthologues directory.


## Export upstream sequences 

The profiles directory contains TF binding profiles predicted by GenomeExplorer (see the manuscript). 

1. For the significance testing of sequence motifs, we use upstream sequences of the gene identified by DAP-seq and its orthologs in other Rhodanobacter genomes. For this analysis, we use only genomes that have orthologs of the regulatory gene and the target gene. 

The prepare_fdrMotif_input.py exports nucleotide sequences of from -350 to -1 bp from the start of the gene, excluding coding regions of neighboring genes. For AcrR, these limits were -350..+10 bp because the predicted TF binding motif partially overlaps the start of the target gene. Upstream regions shorter than 80 bp were excluded from the analysis to remove sequences that do not contain promoters. 

**DO NOT run prepare_fdrMotif_input.py if you want to preserve existing files. This script overwrites \*.target_upstreams.fna and \*.mx files in all subdirectories.**

```
cd motif_analysis

python prepare_fdrMotif_input.py
```

The testing sequence set for the HxlR analysis was manually edited because Orthofinder incorrectly estimated the number of HxlR orthologs. Correct HxlR orthologs were identified by phylogenetic analysis of the HxlR family orthogroup. 

2. Run fdrMotif and collect results. Upper FDR limit is set to 0.0001. Ten sets of background sequences are generated by 0-order Markov model from the set of all upstream sequences from the FW104-10B01 genome (in FW104-10B01.upstreams.fna file). 

```
sh run_fdr_motif.sh
python collect_fdrmotif_results.py
```

The resulting file called fdrMotif_results.txt contains information from fdrMotif summary files, which includes E-value and computed FDR.
